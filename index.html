Progress portability

Everything is stored in localStorage. Exporting gives you a small JSON backup that can be imported on another browser.

Session settings

12 is a good default: long enough for a few delayed retries, short enough to repeat daily.

Scheduling model

A correct retrieval advances the item through expanding intervals: about 5 minutes → 20 minutes → 1 day → 3 days → 7 days → 14 days → 30 days → 90 days. A miss drops the item back and schedules a same-run retry when possible. The model is intentionally transparent rather than pretending to estimate memory with false precision.

For word material, this app does not randomly interleave everything just because “interleaving” is fashionable. It mainly uses spacing, and uses contrastive choice practice where the source test itself requires discrimination.
